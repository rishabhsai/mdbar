## What changed

- Redesigned Settings with clearer notebook, appearance, typography, and shortcut controls.
- Fixed Settings being inaccessible before a notebook folder was selected.
- Added a branded, cleaner drag-to-Applications DMG window.
- Updated the website download buttons to open GitHub Releases, so visitors always see the current build and release notes.

## macOS installation

Download `mdbar-0.1.2-aarch64.dmg`, open it, and drag mdbar into Applications.

This build is signed with a Developer ID certificate and notarized by Apple.
